# 🤖 HR Recruitment Telegram Bot (Telegram-бот для подбора персонала)

Готовое решение Telegram-бота для найма сотрудников с удобной админ-панелью для управления вакансиями и автоматической пересылкой откликов кандидатов в спец-группу/чат HR-отдела.

---

## 🌟 Основные возможности

1. **Кандидаты (Пользователи)**:
   - Просмотр списка открытых вакансий.
   - Просмотр условий, обязанностей, требований и размера оплаты.
   - Подача отклика через пошаговую интерактивную анкету (ФИО, опыт, контакты, резюме).
   - Получение статуса рассмотрения заявки («Принят» / «Отклонен»).

2. **Администраторы (Админ-панель)**:
   - Авторизация по Telegram ID (`ADMIN_IDS` в `.env`).
   - Добавление новых вакансий прямо в Telegram (FSM-пошаговый ввод).
   - Просмотр всех вакансий с индикацией статуса (🟢 Активна / 🔴 Скрыта).
   - Возможность скрывать / публиковать и удалять вакансии.

3. **HR-Группа (Спец-чат для откликов)**:
   - При заполнении анкеты кандидатом бот мгновенно генерирует и отправляет карточку анкеты в указанный Telegram-чат (`TARGET_GROUP_ID`).
   - Кнопки быстрого решения прямо под анкетной карточкой: `✅ Принять`, `❌ Отклонить`, `💬 Написать кандидату`.
   - При принятии решения статус анкеты обновляется в группе (с указанием имени HR-менеджера), а кандидат автоматически получает уведомление в личные сообщения.

## 🛠️ Установка и запуск

### 1. Требования
- Python **3.10** или выше.

### 2. Клонирование / Переход в папку
```bash
cd hrbot
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

---

## ⚙️ Настройка файла `.env`

Создайте или отредактируйте файл `.env` в корневом каталоге проекта:

```env
# Токен вашего бота, полученный у @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Ваш Telegram ID (и ID других админов через запятую)
ADMIN_IDS=123456789

# ID группы/чата для получения откликов
TARGET_GROUP_ID=-1001234567890
```

### 📌 Инструкция по получению данных для `.env`:

1. **`BOT_TOKEN`**:
   - Напишите боту [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot`, укажите имя и username бота.
   - Скопируйте полученный HTTP API Token и вставьте в `BOT_TOKEN`.

2. **`ADMIN_IDS`**:
   - Напишите боту [@userinfobot](https://t.me/userinfobot) или [@myidbot](https://t.me/myidbot).
   - Скопируйте ваш `Id` (число, например `123456789`).
   - Можно указать несколько админов через запятую: `123456789,987654321`.

3. **`TARGET_GROUP_ID`**:
   - Создайте Telegram-группу или супергруппу (например, "HR Отклики").
   - Добавьте вашего бота в эту группу и **назначьте его администратором** (для отправки сообщений).
   - Чтобы узнать ID группы, добавьте в группу бота [@myidbot](https://t.me/myidbot) или [@raw_data_bot](https://t.me/raw_data_bot), либо перешлите сообщение из группы в [@userinfobot](https://t.me/userinfobot).
   - ID группы всегда начинается с `-100` (например: `-1001987654321`).

## 📖 Как пользоваться

### Администратору:
- Нажмите команду `/admin` или кнопку **«⚙️ Админ-панель»** в главном меню бота.
- Нажмите **«➕ Добавить вакансию»** и ответьте на вопросы бота (Название, Описание, Требования, Зарплата).
- Управляйте созданными вакансиями через **«📋 Управление вакансиями»**.

### Кандидатам:
- Нажмите `/start`.
- Выберите **«📋 Открытые вакансии»**.
- Выберите интересующую должность и нажмите **«📝 Откликнуться на вакансию»**.
- Заполните ФИО, опыт работы, контакты и резюме.
- Подтвердите отправку.

### HR-менеджерам в группе:
- В специальную группу придет карточка анкеты кандидата.
- Нажмите **«✅ Принять»** или **«❌ Отклонить»**, либо свяжитесь с кандидатом в один клик по кнопке **«💬 Написать кандидату»**.

## 📁 Структура проекта

```text
hrbot/
├── database/
│   └── db.py               # Инициализация SQLite и методы работы с вакансиями и откликами
├── handlers/
│   ├── admin.py            # Логика админ-панели и создания вакансий
│   ├── group.py            # Обработка действий HR-менеджеров в спец-группе
│   └── user.py             # Интерфейс кандидата и подача откликов
├── keyboards/
│   ├── inline.py           # Inline-кнопки (списки вакансий, кнопки админки, кнопки в группе)
│   └── reply.py            # Главные клавиатуры бота
├── states/
│   ├── application.py      # Состояния FSM для заполнения анкеты
│   └── vacancy.py          # Состояния FSM для создания вакансии
├── .env                    # Переменные окружения (секреты)
├── .env.example            # Пример файла переменных окружения
├── config.py               # Модуль считывания конфигурации
├── main.py                 # Точка входа в приложение
├── requirements.txt        # Зависимости Python
└── README.md               # Документация проекта
```
